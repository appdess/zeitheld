# Code of Conduct

## Our pledge

We pledge to make participation in ZeitHeld a harassment-free experience for
everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

We will act in ways that contribute to an open, welcoming, diverse, inclusive,
and healthy community. Because this project concerns children, privacy-respecting
and age-appropriate conduct is especially important.

## Expected behavior

- Be respectful, constructive, patient, and empathetic.
- Give and accept useful feedback gracefully.
- Focus on what is best for children, families, and the community.
- Respect privacy. Never request or publish a child's identity, recording,
  transcript, location, school, account credential, or generated private data.
- Avoid sexualized, violent, frightening, discriminatory, or exploitative
  content.

Harassment, trolling, personal attacks, doxxing, sexual attention, threats,
and publishing another person's private information are unacceptable.

## Enforcement

Project maintainers may edit, reject, or remove contributions and may restrict
participation when behavior is inappropriate, threatening, offensive, or
harmful. For conduct on GitHub that requires private handling, use GitHub's
[Report Abuse form](https://support.github.com/contact/report-abuse). A public
issue may contain only a minimal, non-sensitive request for maintainer contact;
never put child data or private incident details in it. The maintainer will then
provide a private channel before asking for any incident detail. GitHub Private
Vulnerability Reporting is reserved for software-security vulnerabilities.

All reports will be reviewed and investigated fairly and with respect for the
reporter's privacy. This policy applies in project spaces and when someone is
officially representing the project elsewhere.
